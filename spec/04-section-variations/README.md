# 04 — Section Variations

This folder holds isolated section design explorations for the Dr. Arefin project (project number `04`).

## Folder convention

```
spec/04-section-variations/
  └── {NN}-{section-name}-{YY}/
        ├── 01-audit-gap-{section-name}-{YY}.md
        ├── 02-{section-name}-{YY}.md            (the variation specs + animations)
        └── 03-{section-name}-{YY}-colors-themes.md
```

- `NN` = sequential index inside this folder, starting at `01`
- `{section-name}` = kebab-case section identifier (e.g. `hero`)
- `YY` = custom 2-digit project sequence — for Dr. Arefin this is `04`

Corrections live in `spec/04-section-corrections/` (mirrored convention).
