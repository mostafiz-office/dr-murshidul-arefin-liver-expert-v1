## Variation A — "Authority Split" (trust-first)

**UX hypothesis:** First-time visitors decide on a surgeon by *visible authority*. Show the surgeon + credentials in one glance, no scroll.

### Layout
- 12-col grid: **left 7 cols** (text, CTAs, trust strip) · **right 5 cols** (portrait in soft-rounded frame with primary halo).
- Mobile: stacks portrait → text.
- Min height: `min(720px, 92vh)` desktop, `auto` mobile.

### Background
- Base: `hsl(var(--background-deepest))` (deep green-black, `#061314`-ish).
- One off-center radial gradient: `radial-gradient(60% 80% at 25% 35%, hsl(var(--primary) / 0.18) 0%, transparent 70%)` — soft ambient green.
- Subtle SVG noise texture at 4% opacity (optional, perf-light).

### Portrait treatment
- Wrapped in `arefin-image-frame` rounded `2rem`, 1px primary/15 border.
- Behind it: a softly pulsing primary halo (`0 0 60px 10px hsl(var(--primary)/0.18)`), 4s ease-in-out infinite.

### Trust strip
- Inline row under CTAs, 4 items separated by a vertical primary-colored divider.
- Each item: `Ubuntu 700 18px` value + `Poppins 400 12px uppercase tracking-wide` label.

### Animations (CSS3, 0.3s base)
| Element | Animation | Duration | Delay |
|---------|-----------|----------|-------|
| Eyebrow | `hero-fade-up` | 0.3s | 0s |
| Title line 1 | `hero-fade-up` | 0.3s | 0.05s |
| Title line 2 (highlight) | `hero-fade-up` | 0.3s | 0.1s |
| Subtitle | `hero-fade-up` | 0.3s | 0.2s |
| CTA row | `hero-fade-up` | 0.3s | 0.3s |
| Trust strip | `hero-fade-up` | 0.3s | 0.4s |
| Portrait | `hero-portrait-in` (scale 0.96 → 1 + fade) | 0.3s | 0.15s |
| Halo | `hero-pulse-glow` | 4s ease-in-out infinite | 0.5s |

```css
@keyframes hero-fade-up { from { opacity: 0; transform: translateY(16px); } to { opacity: 1; transform: translateY(0); } }
@keyframes hero-portrait-in { from { opacity: 0; transform: scale(0.96); } to { opacity: 1; transform: scale(1); } }
@keyframes hero-pulse-glow { 0%, 100% { box-shadow: 0 0 40px 6px hsl(var(--primary)/0.12); } 50% { box-shadow: 0 0 80px 14px hsl(var(--primary)/0.28); } }
```

## Variation B — "Credential Cards Float" (credibility-first)

**UX hypothesis:** Comparison-stage patients ask *"why him?"*. Floating credential chips orbit the portrait so the answer is the visual.

### Layout
- Centered text block (top), portrait positioned bottom-right at ~40% viewport width.
- 3 floating "credential cards" anchored around the portrait (top-left, mid-left, bottom-right).
- Mobile: portrait stacks below text; floating cards collapse into an inline horizontal pill row.

### Background
- Base: `hsl(var(--background-deepest))`.
- Mesh gradient using 2 stacked radials:
  - `radial-gradient(40% 50% at 80% 20%, hsl(var(--primary)/0.22) 0%, transparent 70%)`
  - `radial-gradient(50% 60% at 10% 90%, hsl(160 50% 25% / 0.35) 0%, transparent 70%)`
- Optional 1px grid pattern at 4% opacity (Tailwind `bg-grid` or inline SVG).

### Floating credential cards (3 cards)
| Card | Content | Position (desktop) |
|------|---------|--------------------|
| C1 | `★ FCPS · MS Hepatobiliary` | top-left of portrait |
| C2 | `20+ Years · 1500+ Surgeries` | mid-left of portrait |
| C3 | `Popular Medical College Hospital, Dhanmondi` | bottom-right of portrait |

- Card surface: `bg-card/90 backdrop-blur-md border border-primary/20 rounded-xl shadow-lg px-4 py-3`.
- Each card *gently floats* on a 4–6s sine loop with a 0.5s phase offset so they never sync.

### CTA pill
- Reuses the existing `CallBookPill` Call/Book toggle from `DrArefinHeader`.
- Add a 0.3s sliding active-indicator (already in spec) — no behavior change.

### Animations (CSS3)
| Element | Animation | Duration | Delay |
|---------|-----------|----------|-------|
| Title (split into 2 lines, sequential reveal) | `hero-fade-up` per line | 0.3s | 0s, 0.1s |
| Subtitle | `hero-fade-up` | 0.3s | 0.2s |
| CTA row | `hero-fade-up` | 0.3s | 0.3s |
| Portrait | `hero-fade-in` | 0.3s | 0.15s |
| Card C1 | `hero-card-in` (scale 0.92 → 1 + fade) | 0.3s | 0.45s |
| Card C2 | `hero-card-in` | 0.3s | 0.55s |
| Card C3 | `hero-card-in` | 0.3s | 0.65s |
| Cards (loop) | `hero-float` ±6px on Y | 4–6s ease-in-out infinite | staggered phase |

## Variation C — "Spotlight Ray" (focus-first, no form)

**UX hypothesis:** High-intent visitors scan for *availability* and *contact*. A single vertical green light bar visually anchors the portrait + a live "available today" pulse anchors the CTA — no clutter.

### Layout
- Asymmetric 60/40: **left 60%** title + subtitle + CTA stack + live-availability strip · **right 40%** portrait with vertical primary accent bar (4px wide, full height of portrait, sits flush left).
- Mobile: portrait moves above text; accent bar becomes a horizontal underline.

### Background
- Base: `hsl(var(--background-deepest))`.
- One diagonal "light ray": `linear-gradient(135deg, transparent 0%, transparent 55%, hsl(var(--primary)/0.10) 60%, transparent 65%)` slowly drifting (8s loop, ±3% translate).
- No orbs, no mesh — minimum visual noise, maximum focus.

### Live-availability strip (under CTA)
- Pulsing 8px primary dot + `Available today at Popular Medical College Hospital, Dhanmondi`.
- Dot uses `hero-pulse-dot` 1.5s loop.
- This strip is purely visual — clicking it scrolls to `/contact/` or triggers `tel:` on mobile (no form logic).

### Animations (CSS3)
| Element | Animation | Duration | Delay |
|---------|-----------|----------|-------|
| Eyebrow | `hero-fade-up` | 0.3s | 0s |
| Title | `hero-fade-up` | 0.3s | 0.1s |
| Subtitle | `hero-fade-up` | 0.3s | 0.2s |
| CTA row | `hero-fade-up` | 0.3s | 0.3s |
| Availability strip | `hero-fade-up` | 0.3s | 0.4s |
| Portrait | `hero-portrait-in` | 0.3s | 0.15s |
| Accent bar | `hero-bar-grow` (height 0 → 100%) | 0.3s | 0.45s |
| Pulse dot | `hero-pulse-dot` | 1.5s ease-in-out infinite | 0.7s |
| Light ray | `hero-ray-drift` ±3% translate | 8s ease-in-out infinite | 0s |

```css
@keyframes hero-bar-grow { from { transform: scaleY(0); transform-origin: top; } to { transform: scaleY(1); } }
@keyframes hero-pulse-dot { 0%, 100% { box-shadow: 0 0 0 0 hsl(var(--primary)/0.6); } 50% { box-shadow: 0 0 0 8px hsl(var(--primary)/0); } }
@keyframes hero-ray-drift { 0%, 100% { transform: translate(0, 0); } 50% { transform: translate(3%, -3%); } }
```

## Implementation rules (all variations)

1. **Tokens only** — colors/fonts via `hsl(var(--…))` and `font-arefin-heading` / `font-arefin`. No raw hex, no `text-white`/`bg-black`.
2. **No `!important`**, no inline styles for color (only for `style={{ animationDelay }}` patterns already in the project).
3. **Reduced motion** — all infinite loops respect `@media (prefers-reduced-motion: reduce)` (already enforced globally in `index.css`).
4. **Portrait** — single source `src/assets/arefin-hero-portrait-real.png`, `loading="eager"`, `fetchpriority="high"`.
5. **A11y** — H1 only inside the hero. CTA buttons have `aria-label`. Decorative orbs/bars get `aria-hidden="true"`.
6. **Performance** — all animations use `transform` / `opacity` only. No `width`/`height`/`top`/`left` animated.
